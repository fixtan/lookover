# 吹き出し・文字注釈の実装メモ (Lookover)

2026-10-17 の相談の記録。目標は Screenpresso の「吹き出し」と同じ見た目・操作。
読んだ範囲: `annotate.js` 全部、`edit.js` 全部、`main.js` の先頭から `ACTIONS` の手前まで、`DESIGN.md`。
**未読 (実装前に必ず読む)**: `main.js` 後半 (pointer / dblclick / keydown / 設定欄の結線 / HANDLERS / 起動)、`keys.js` の ACTION_TABLE、`ui.js` (入力枠)、`index.html` (パネルの HTML)。

## 確定した仕様 (Lain の指定)

- 箱の大きさに文字を合わせる (Canva と同じ)。箱を変えると文字の倍率も変わる
- 文字の大きさは、それとは別に変えられる
- 箱からはみ出した文字は **非表示** (箱でクリップ)
- 尖りの根もとは **自動**。根もとの太さだけ調整できる。辺の長さに対する割合で持つ (辺 100px なら 10〜90px の範囲)
- 文字だけの注釈 (箱も尖りもなし) も作れる
- 配置後に、位置・大きさ・尖りの先端を編集できる
- 縁取りとグロー (光彩) あり

## 僕の解釈 (違っていたら直す)

- 角のつまみ = 縦横比を保って拡縮し、**文字の大きさも一緒に変わる**。辺のつまみ = 箱だけ変わり、文字はそのまま (はみ出し分は非表示)。Canva の挙動の解釈
- 改行は手入力 (Enter)。自動折り返しはしない
- 作り方: ドラッグで箱を作る → すぐ文字入力 → 確定したとき 1 回だけ、文字が箱に収まる大きさに自動調整 → 尖りの先端は初期値 (箱の下) に置いて、つまみで動かす
- 文字だけ = 同じマークで「箱: なし」「尖り: なし」。見えない箱が、つまみ・当たり判定・クリップの範囲になる

## データ

`edit.marks` に新しい種類 `callout` を足す。座標系は既存と同じ (向きを反映した後・切り抜く前の画像座標)。

```
{ type: 'callout',
  x, y, w, h,          // 箱
  tx, ty,              // 尖りの先端
  text: '…\n…',        // 手動改行
  fs,                  // 文字の基準サイズ (画像 px)
  font,                // 例: "'Meiryo UI','Yu Gothic UI',sans-serif"
  box: true, tip: true,
  root: 0.3,           // 根もとの太さ。辺の長さに対する割合 (0.1〜0.9)
  fill, textColor,
  color, lw, opacity, shadow, radius,   // 既存の項目をそのまま使う (縁の色・太さ・不透明度・影・角丸)
  glow }               // 光彩 (色は color か別項目。要決定)
```

## 既存コードで押さえること (読んだ範囲の事実)

1. **`annotate.js` は「枠でなければ矢印」の分岐になっている。** `normStyle` (frame 以外は taper を持つ)、`drawPen` (frame 以外は矢印を描く)、`describeStyle` (frame でなければ taper を見る)。`callout` を足すときは、3 か所とも `callout` の分岐を明示する。そうしないと矢印として描かれる
2. `PEN_TOOLS` に `'callout'` を足すと、`penTarget` (設定パネルの対象)、`markUp` の `applyStyle`、登録 1〜5 (`penPreset`) が、そのまま使える。`PEN_DEFAULT.callout` も要る
3. **`edit.js` の回転・反転 (`rectCW` / `rectCCW` / `rectFlipH` / `rectFlipV`) は `x y w h dir` だけを変換し、ほかは `...r` で素通しにする。** 先端 `tx, ty` を足すと、回転しても動かず、違う場所を指す。この 4 関数に先端の変換を足す必要がある。文字は水平のまま、箱の位置・大きさだけが写る形になる (箱の w と h は入れ替わる)
4. `drawMark` (edit.js) の `m.type === 'frame' || m.type === 'arrow'` に `callout` を足し、`drawCallout(g, m, r)` を `annotate.js` に作る。`clampRect` は箱だけに効く。先端は別に、画像の範囲へ収める
5. `rebuild` の再描画の判定は `JSON.stringify([…, e.marks, …])` なので、文字や先端を変えれば自動で作り直される。追加の作業は要らない
6. `markHandles` に `tip` を足せば、`markHandleAt` / `drawMarks` の描画は拾う。ただし `drawMarks` は「矢印なら丸、それ以外は四角」なので、先端だけ丸にする分岐が要る
7. `markResized` に分岐を足す: `h === 'tip'` は先端を動かす。角のつまみは縦横比を保って拡縮し、`fs` も同じ比で変える。辺のつまみは箱だけ変える
8. `markAt` (当たり判定) は箱だけを見ている。先端は箱の外にあるので、先端の三角形の近くも当たりにする
9. `MARK_TOOLS` / `TOOL_NAMES` / `ACTIONS` (`'mark-callout'`) / パネルのボタン (index.html) / `keys.js` のキー割り当てに、道具を 1 つ足す
10. 設定欄は `pen-opts` を使い回し、`callout` のときだけ「文字の大きさ・文字色・塗り色・根もとの太さ・箱/尖りの有無・光彩」を出す

## 描き方 (drawCallout)

1. 箱 (角丸) と尖りを **1 つのパス** にまとめる。矢印を多角形 1 回で塗っているのと同じ理由で、不透明度をかけても重なって濃くならない
2. 尖りの根もとの辺は、先端が箱の外のどちら側にあるかで決める (左右か上下かは、箱の幅と高さで正規化した差の大きいほう)。根もとの中心は辺の中央、太さは `辺の長さ × root`。先端が箱の中にあるときは尖りを描かない
3. 塗り → 縁 (`stroke`) → 影 / 光彩 (`shadowBlur`)。光彩は、同じパスを 2 回描くと強くなる
4. 文字: `g.save()` → 箱でクリップ (`clip`) → `font = ${fs}px ${font}` → 行ごとに中央揃えで `fillText`。文字の縁取りは `strokeText` を先に描く
5. 箱なし (`box: false`) は、手順 3 の塗り・縁を飛ばして、文字だけを描く

## 実装の順 (途中で動作を確認できるように分ける)

- **段階 1: 文字だけの注釈** — マークの追加、描画、選択・移動・辺と角のつまみ、文字入力 (ダブルクリック)、取り消し、回転で崩れないこと
- **段階 2: 箱 + 尖り** — 先端のつまみ、根もとの自動決定、回転・反転での先端の変換
- **段階 3: 見た目** — 根もとの太さ、縁取り、光彩、塗り色・文字色
- **段階 4: 登録 (1〜5)** — 既存のプリセットに乗せる

各段階の最後に `node test/ui.mjs` を通す。段階 2 で、回転・反転のテストを足す。
